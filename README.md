# claude-for-arc

Расширение для браузера **Arc** и MCP-сервер, через которые приложение Claude на Mac может открывать вкладки, читать страницы, кликать и заполнять формы в Arc.

> Проект основан на [OpenDia](https://github.com/aeonfun/opendia) (лицензия MIT) и переделан с упором на безопасность.

## Зачем

Официальное расширение Claude in Chrome в Arc не работает: оно держит вкладки в группах вкладок, а в Arc их нет. claude-for-arc группы вкладок не использует.

## Установка (коннектор, 2 минуты)

Нужны macOS, браузер Arc и приложение Claude. Node.js ставить не нужно: коннектор работает на Node, встроенном в Claude.

1. Скачайте коннектор (нужен доступ к этому репозиторию на GitHub): **[claude-for-arc.mcpb](https://github.com/eburinu/claude-for-arc/releases/latest/download/claude-for-arc.mcpb)**
2. Откройте файл двойным кликом. Claude покажет окно установки, нажмите **«Установить»**.
3. Коннектор сам положит расширение в папку `~/claude-for-arc/extension` вместе с ключом и откроет в Arc страницу `arc://extensions` и эту папку в Finder. В Arc:
   - включите **«Режим разработчика»** (Developer mode, справа вверху);
   - нажмите **«Загрузить распакованное»** (Load unpacked) и выберите папку `extension` (её можно перетащить из Finder).

Всё. Расширение подключится само, в окне расширения будет «Подключено к Claude». Пользоваться можно и в чатах, и во вкладке Code: например, «через claude-for-arc открой example.com и перескажи».

**Обновление:** скачайте новый `.mcpb` по той же ссылке и откройте его. Расширение в Arc обновится и перезапустится само.

Если расширение пишет **«Сервер не запущен»**: откройте приложение Claude (коннектор работает, пока оно открыто) и проверьте, что claude-for-arc включён в Настройки → Расширения.

<details>
<summary>Старый способ: установщик из архива (нужен Node.js 18+)</summary>

1. Распакуйте архив `claude-for-arc-<версия>.zip` и дважды щёлкните **«Установить.command»** (если macOS не даёт открыть: правой кнопкой → «Открыть»).
2. Установщик скопирует файлы в `~/claude-for-arc`, создаст ключ в `~/Library/Application Support/claude-for-arc/token`, положит его в папку расширения, подключит сервер к Claude Code (и по желанию к чату) и покажет, как загрузить расширение в Arc.
3. Сервер из установщика работает, только пока открыта сессия во вкладке Code. Если расширение пишет «Сервер не запущен», начните новую сессию или запустите диагностику: `bash ~/claude-for-arc/scripts/doctor.sh`.

## Безопасность

Сервер и расширение общаются только через `127.0.0.1`, а перед любой командой проверяют друг друга по секретному ключу (взаимный HMAC). Поэтому:

- **сайты и другие расширения** не могут подключиться к серверу: они отсекаются по адресу и по ID расширения, а ключа у них нет;
- **другая программа на этом порту** не может управлять браузером: расширение выполняет команды только от сервера, который знает ключ;
- **HTTP-эндпоинта и туннеля нет**, в отличие от OpenDia. Команды отдаёт только приложение Claude, которое запустило сервер.

В окне расширения можно настроить:

| Настройка | По умолчанию | Что делает |
|---|---|---|
| Только вкладки, открытые Claude | **вкл** | Claude видит и трогает только вкладки, которые открыл сам. Ваши вкладки скрыты, даже из списка |
| Только чтение | выкл | Запрещает клики, ввод, изменение стилей, закрытие вкладок |
| История и закладки | **выкл** | Инструменты истории и закладок появляются только после разрешения (Arc спросит подтверждение) |
| Запрещённые сайты | менеджеры паролей | Сайты, которые никогда не открываются и не читаются (вместе с поддоменами) |
| Пауза | выкл | Мгновенно запрещает любые действия |

Работает всегда:
- поля паролей, одноразовых кодов и данных карт Claude **не заполняет и не читает**;
- открывать можно только `http`/`https`: никаких `javascript:`, `file:`, `arc://`, магазинов расширений;
- скрипт расширения попадает на страницу, только когда Claude с ней работает, а не на все сайты подряд;
- в окне расширения есть журнал последних действий.

**Ограничения.** Программа, запущенная от вашего пользователя macOS, может прочитать файл с ключом. От вредоносной программы на самом Mac это не защищает, но от неё не защищает и браузер. Клики имитируются через код страницы, поэтому на некоторых сайтах (сложные формы, защита от ботов) они могут не срабатывать. Скриншотов пока нет.

## Несколько сессий Claude

Каждая сессия запускает свой сервер. Браузером управляет самая новая, остальные ждут. Когда она закрывается, управление переходит к следующей.

## Для разработки

```bash
cd server && npm ci && cd ..
node --test --test-concurrency=1 server/test/ tests/   # тесты
node tests/worker.e2e.mjs                              # расширение + сервер вместе
node tests/live-arc.mjs                                # все инструменты в настоящем Arc (см. комментарий в файле)
bash scripts/install.sh                                # установка из репозитория
bash scripts/make-mcpb.sh                              # коннектор dist/claude-for-arc.mcpb
gh release create v<версия> dist/claude-for-arc.mcpb   # ссылка .../releases/latest/download/claude-for-arc.mcpb
bash scripts/make-release.sh                           # архив dist/claude-for-arc-<версия>.zip (старый способ)
```

Устройство:
- `server/server.js`: MCP по stdio и мост WebSocket с проверкой ключа;
- `server/format.js`: форматирование ответов из OpenDia;
- `extension/src/background/guard.js` и `policy.js`: правила доступа;
- `extension/src/background/background.js`: подключение и инструменты (основа из OpenDia);
- `extension/src/content/content.js`: работа со страницей.

ID расширения закреплён ключом в `manifest.json`: `dllpmmijlpleaoifjffigbcilgmhjpla`. Сервер принимает только его.
