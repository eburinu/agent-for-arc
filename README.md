# claude-for-arc

Неофициальное расширение для браузера **Arc** и MCP-сервер, через которые приложение Claude на Mac может открывать вкладки, читать страницы, кликать и заполнять формы в Arc.

> Это не продукт Anthropic и не связано с ней. Проект основан на [OpenDia](https://github.com/aeonfun/opendia) (лицензия MIT) и переделан с упором на безопасность.

## Зачем

Официальное расширение Claude in Chrome в Arc не работает: оно держит вкладки в группах вкладок, а в Arc их нет. claude-for-arc группы вкладок не использует.

## Что нужно

- macOS и браузер Arc;
- приложение Claude (вкладка Code, по желанию также Chat);
- Node.js 18 или новее ([nodejs.org](https://nodejs.org), версия LTS). Проверить: `node -v` в Терминале.

## Установка

1. Распакуйте архив `claude-for-arc-<версия>.zip`.
2. Дважды щёлкните **«Установить.command»**. Если macOS не даёт открыть файл, нажмите на нём правой кнопкой → «Открыть». Или откройте Терминал и выполните:
   ```bash
   bash ~/Downloads/claude-for-arc-0.1.0/scripts/install.sh
   ```
3. Следуйте подсказкам установщика. Он:
   - скопирует файлы в `~/claude-for-arc`;
   - создаст секретный ключ подключения в `~/Library/Application Support/claude-for-arc/token`;
   - подключит сервер к Claude;
   - покажет, как загрузить расширение в Arc: `arc://extensions` → «Режим разработчика» → «Загрузить распакованное» → папка `~/claude-for-arc/extension`;
   - скопирует ключ в буфер обмена: вставьте его в окно расширения (значок на панели Arc) и нажмите «Сохранить».
4. Начните новую сессию в Claude. Появятся инструменты `claude-for-arc`.

Обновление: распакуйте новую версию и запустите установщик снова. Ключ сохранится. Потом в `arc://extensions` нажмите «Обновить» у расширения.

Удаление:
```bash
bash ~/claude-for-arc/scripts/uninstall.sh
```
Затем удалите расширение в `arc://extensions`.

## Безопасность

Сервер и расширение общаются только через `127.0.0.1`, а перед любой командой проверяют друг друга по секретному ключу (взаимный HMAC). Поэтому:

- **сайты и другие расширения** не могут подключиться к серверу: они отсекаются по адресу и по ID расширения, а ключа у них нет;
- **другая программа на этом порту** не может управлять браузером: расширение выполняет команды только от сервера, который знает ключ;
- **HTTP-эндпоинта и туннеля нет**, в отличие от OpenDia. Команды отдаёт только приложение Claude, которое запустило сервер.

В окне расширения можно настроить:

| Настройка | По умолчанию | Что делает |
|---|---|---|
| Только вкладки, открытые Claude | **вкл** | Claude видит и трогает только вкладки, которые открыл сам. Ваши вкладки скрыты, даже из списка |
| Только чтение | выкл | Запрещает клики, ввод, изменение стилей, закрытие вкладок |
| История и закладки | **выкл** | Инструменты истории и закладок появляются только после разрешения (Arc спросит подтверждение) |
| Запрещённые сайты | менеджеры паролей | Сайты, которые никогда не открываются и не читаются (вместе с поддоменами) |
| Пауза | выкл | Мгновенно запрещает любые действия |

Работает всегда:
- поля паролей, одноразовых кодов и данных карт Claude **не заполняет и не читает**;
- открывать можно только `http`/`https`: никаких `javascript:`, `file:`, `arc://`, магазинов расширений;
- скрипт расширения попадает на страницу, только когда Claude с ней работает, а не на все сайты подряд;
- в окне расширения есть журнал последних действий.

**Ограничения.** Программа, запущенная от вашего пользователя macOS, может прочитать файл с ключом. От вредоносной программы на самом Mac это не защищает, но от неё не защищает и браузер. Клики имитируются через код страницы, поэтому на некоторых сайтах (сложные формы, защита от ботов) они могут не срабатывать. Скриншотов пока нет.

## Несколько сессий Claude

Каждая сессия запускает свой сервер. Браузером управляет самая новая, остальные ждут. Когда она закрывается, управление переходит к следующей.

## Для разработки

```bash
cd server && npm ci && cd ..
node --test --test-concurrency=1 server/test/ tests/   # тесты
bash scripts/install.sh                                # установка из репозитория
bash scripts/make-release.sh                           # архив dist/claude-for-arc-<версия>.zip
```

Устройство:
- `server/server.js`: MCP по stdio и мост WebSocket с проверкой ключа;
- `server/format.js`: форматирование ответов из OpenDia;
- `extension/src/background/guard.js` и `policy.js`: правила доступа;
- `extension/src/background/background.js`: подключение и инструменты (основа из OpenDia);
- `extension/src/content/content.js`: работа со страницей.

ID расширения закреплён ключом в `manifest.json`: `dllpmmijlpleaoifjffigbcilgmhjpla`. Сервер принимает только его.
